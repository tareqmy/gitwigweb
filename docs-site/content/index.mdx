# 🌿 Gitwig Documentation

Welcome to the official documentation for **Gitwig** — a modern, keyboard-driven Terminal Git UI built with Rust and [Ratatui](https://ratatui.rs/).

Gitwig brings the power of graphical Git clients like SourceTree to your terminal, with blazing-fast performance and an intuitive interface.

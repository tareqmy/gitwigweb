Installation

Gitwig is built in Rust and can be easily installed via Cargo, Rust's package manager.

cargo install gitwig

Alternatively, you can build from source:

git clone https://github.com/tareqmy/gitwig.git
cd gitwig
cargo build --release
sudo cp target/release/gitwig /usr/local/bin/

Quickstart

To start using Gitwig, simply navigate to any Git repository on your terminal and run:

gitwig

If the directory is not a Git repository, Gitwig will notify you or allow you to initialize one.

Core Features

  • Status Indicators: Real-time per-card status indicators for branches, worktrees, and stashes.
  • Detail View: Press `Enter` on any branch to see an on-demand detail view of commits and changes.
  • Modals: Clean modal input for branch creation, committing, and tagging.
  • Configuration: TOML based configuration editable from within the app.

Keybindings

Gitwig is fully keyboard-driven. Below are the basic navigation keys:

Key Action
j / ↓ Move down
k / ↑ Move up
Enter Inspect/Detail view
c Commit changes
q / Esc Quit/Close modal
? Open Help overlay

Keybindings

Gitwig is a fully keyboard-driven application. Mastering these shortcuts will make you incredibly fast.

Global Navigation

Key Action
j / ↓ Move cursor down
k / ↑ Move cursor up
Enter Open Detail/Inspect view for the selected item
Esc / q Close current modal or quit application (from main menu)
? Toggle the Help Overlay (Context Aware)
Ctrl+F Open Global Code Search
/ Open Fuzzy Jump Picker to search repos by name
Shift+U Open Usage Dashboard

Repository Management

Key Action
a Add a new repository tracking card
e Edit selected repository card
d Remove repository tracking card (Does not delete files)
* Toggle Star / Favorite for selected repository
v Cycle view modes (Standard, Compact, Grid)

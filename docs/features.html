Core Features

A deep dive into what makes Gitwig incredibly powerful and intuitive.

Fullscreen Terminal UI

Designed using ratatui and crossterm with modern visual styling. Experience a clean, bordered layout presenting branches, worktrees, and stashes at a glance—reminiscent of SourceTree but right in your terminal.

Background Auto-Refresh

Non-blocking background status checking every 10 seconds keeps your repo cards live and up-to-date, without freezing the UI or interrupting your workflow.

Full-Screen Detail View

Press Enter on any repo to open a multi-tab inspection interface containing:

  • Workspace & Files tree with diff preview
  • Graph log and history
  • Branches, Tags, and Remotes
  • Stashes and Worktrees
  • Submodules and Reflog

Global Code Search

Press Ctrl-F to search for string patterns across all tracked repositories using a fast, multithreaded offline file scanner. Hitting Enter on a result automatically jumps to and opens that repository.

App Usage Dashboard

Press Shift+U to open the usage statistics dashboard tracking session duration, commit counts, repository imports, authored lines of code, Git operations (merges, rebases, fetches), and a visual 52-week Activity Heatmap.

Forge / GitHub Integration

Dedicated PR/MR Viewer tab fetching PRs, status checks, and reviews. Code Review Mode features wizard input popups to asynchronously post line comments directly to PRs from the terminal.
